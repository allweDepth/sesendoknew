# Font Swakelola TCPDF

Definisi TCPDF Unicode Helvetica Neue, Book Antiqua dan Times New Roman,
masing-masing regular/bold/italic/bold-italic,
dibentuk dari font pada komputer kerja untuk mempertahankan ukuran glyph Word.
Tidak ada pengubahan font pada dokumen sumber pengguna. Font PDF disubset pada
saat cetak. Arial menggunakan definisi `tata_naskah` aplikasi yang sudah ada.
